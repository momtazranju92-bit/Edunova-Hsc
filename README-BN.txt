EduNova — HSC 2025–2026 (ব্যক্তিগত ব্যবহার)

ফাইল:
- index.html: মূল ওয়েবসাইট
- manifest.json: অ্যাপ ইনস্টল সেটিংস
- sw.js: অফলাইন ক্যাশ
- icons/: অ্যাপ আইকন

শুরু:
1) index.html ব্রাউজারে খুললে স্থানীয়ভাবে কিছু ফিচার পরীক্ষা করা যাবে, তবে Install App/অফলাইন PWA-এর জন্য HTTPS-এ হোস্ট করতে হবে।
2) GitHub-এ নতুন public repository তৈরি করে এই ফোল্ডারের ভেতরের ফাইলগুলো আপলোড করো (index.html root-এ থাকবে; icons ফোল্ডারও আপলোড করতে হবে)।
3) Repository Settings → Pages → Deploy from a branch → main → /(root) → Save।
4) তৈরি হওয়া HTTPS URL Chrome-এ খুলে ⋮ → Install app / Add to Home screen।
5) অগ্রগতি ও নোট একই ব্রাউজার/ডিভাইসে সেভ হয়। ব্রাউজারের ডেটা মুছে ফেললে তা হারাতে পারে, তাই Backup বোতাম ব্যবহার করো।

সিলেবাস নোট:
এই অ্যাপের টপিক তালিকা একটি প্রাথমিক অধ্যয়ন-ট্র্যাকার; এটি সরকারি পূর্ণাঙ্গ সিলেবাসের প্রতিলিপি নয়। HSC 2025–26-এর জন্য কলেজ/বোর্ডের নির্দেশনা এবং NCTB বইয়ের সঙ্গে প্রতিটি অধ্যায় মিলিয়ে নেবে।
